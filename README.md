# 💼 Gestor de Empleados con Funciones — PyCompany

Un pequeño sistema de consola desarrollado en **Python**, pensado para aprender a estructurar un programa real a partir de funciones, control de flujo y trabajo en equipo.  
El proyecto simula un **gestor interno de empleados** para una empresa ficticia llamada **PyCompany**, que permite **registrar trabajadores, calcular bonos salariales y mostrar resúmenes personalizados**.

---

## 🚀 ¿Qué hace este programa?

El **Gestor de Empleados** permite realizar tres acciones principales desde un menú interactivo:

1. **Registrar datos de un empleado:**  
   Se ingresan nombre, edad, cargo, sueldo base y porcentaje de bono.  
   Los datos se almacenan temporalmente mientras el programa está en ejecución.

2. **Calcular el bono:**  
   A partir del sueldo base y el porcentaje ingresado, el sistema calcula el **monto total a recibir**, mostrando el resultado de manera clara y formateada.

3. **Mostrar el resumen del trabajador:**  
   Muestra toda la información del empleado, incluyendo el **sueldo total con el bono aplicado**.

Finalmente, al salir, se muestra un mensaje de despedida que simula el cierre de sesión de un sistema interno de recursos humanos.

---

## ⚙️ ¿Por qué es útil?

Aunque se trata de un ejercicio educativo, este programa representa la **base de cualquier sistema administrativo**.  
Los conceptos aplicados aquí —funciones, estructuras de control y modularización— son los mismos que se usan en sistemas de nómina, gestión de RRHH, o plataformas internas de empresas.

👉 En la práctica, este tipo de estructura sirve para:
- Calcular bonos, descuentos o sueldos netos.
- Registrar información temporal de empleados.
- Entender cómo dividir responsabilidades entre módulos o archivos.
- Simular un flujo real de menú en consola (como los que se usan en terminales administrativas o scripts de mantenimiento).
